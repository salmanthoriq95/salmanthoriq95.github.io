# salmanthoriq95.github.io

Personal portfolio and writing by Salman Thoriq Al Farisyi, built with Astro and deployed to GitHub Pages.

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npx astro dev --background` | Start the local development server |
| `npx astro dev stop` | Stop the background development server |
| `npm run build` | Build the production site to `dist/` |
| `npx astro check` | Run Astro and TypeScript diagnostics |

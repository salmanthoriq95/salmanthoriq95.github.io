File ini adalah contoh dan tidak ditampilkan di website karena menggunakan
`draft: true`. Salin atau ubah file ini saat ingin menerbitkan tulisan pertama.

## Judul bagian

Tulisan dapat menggunakan seluruh fitur Markdown biasa, termasuk daftar:

- poin pertama;
- poin kedua; dan
- poin ketiga.

### Potongan kode

```ts
const greeting = "Halo dunia";
```

Setelah tulisan siap, ubah `draft` menjadi `false`. Halaman artikel, topik,
filter bahasa, dan preview homepage akan dibuat otomatis saat project dibangun.
